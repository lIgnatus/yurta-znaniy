# «Юрта знаний» — сайт-визитка

Одностраничный сайт образовательного проекта Елены Владимировны Нагимовой «Юрта знаний» (башк. «Белем тирмәһе»): настольно-дидактические игры для изучения башкирского языка и культуры родного края.

**Сайт:** https://lignatus.github.io/yurta-znaniy/
**Репозиторий:** https://github.com/lIgnatus/yurta-znaniy

Сайт статический: HTML, CSS и немного JavaScript, без сборки и без сервера. Работает на GitHub Pages.

## Что на странице

1. **Первый экран.** Девиз «Играя — изучай свой край» и карточка «Семья», которая переключается между языками: русский, башкирский, татарский, английский (в продаже), узбекский, казахский, белорусский (в работе). Последняя вкладка «+» приглашает партнёров.
2. **О проекте.** Как игра учит языку, девять букв башкирского алфавита.
3. **Каталог.** 18 игр и пособий с ценами и ссылками «Купить» на alenmart.ru, фильтр по языку, комплекты для учреждений, где ещё продаются игры.
4. **Методика.** Решение учебно-методического совета при Минобрнауки РБ, БГПУ им. М. Акмуллы, консультанты.
5. **Благодарности и награды.** Две карусели друг под другом: благодарственные письма, сертификаты и методики. Документы открываются по клику, внутри карусели их можно листать.
6. **Команда и международные форумы.** Рассказ автора и короткий ряд команды с именем и ролью: по клику выезжает карточка с фото, должностью и описанием.
7. **Партнёрам и контакты Елены.** WhatsApp, телефон, почта, адрес.

assets/fonts/           шрифты Podkova и Golos Text (лицензия OFL), с башкирскими буквами
assets/img/games/       обложки игр
assets/img/letters/     письма и награды (полный размер и *-thumb для превью)
assets/img/photos/      фото Елены и с форумов
assets/img/brand/       логотип с детьми и юртой, куница
assets/img/og-image.jpg картинка для превью ссылки в мессенджерах

Файлы `*.webp.json` рядом с картинками хранят, откуда взято каждое изображение.

## Как поменять

Все тексты, цены и ссылки находятся в `index.html`. Его можно открыть в любом редакторе и найти нужное через поиск.

- **Контакты.** Ищите `79177521702` (WhatsApp и телефон) и `elena0721@mail.ru`. Они встречаются в шапке и в блоке «Ваш язык?» внизу.
- **Цены.** Каталог находится в `<section class="games">`, цена каждой игры записана в `<span class="price">`. Сейчас цены сверены с alenmart.ru на октябрь 2026 года.
- **Новая игра.** Скопируйте блок `<article class="game">…</article>` и поменяйте картинку, название, текст, цену и ссылку. Картинку положите в `assets/img/games/` в формате WebP шириной около 760 px. В атрибуте `data-lang` перечислите языки игры: `ru`, `ba`, `tt`, `en`. По ним работает фильтр. Затем обновите числа в кнопках фильтра.
- **Новое письмо или сертификат.** Положите скан в `assets/img/letters/` в двух размерах (около 1240 px и превью 520 px) и скопируйте блок `<li class="letter">…</li>` в нужную карусель. Кнопки листания появляются сами, когда документы перестают помещаться.
- **Фото участника команды.** Положите квадратный портрет в `assets/img/team/` и впишите путь в `data-photo` у кнопки участника, например `data-photo="assets/img/team/nafikova.webp"`. Пока `data-photo` пустой, на выезжающей карточке показываются инициалы.
- **Новый участник команды.** Скопируйте блок `<li>` с кнопкой `class="person"`. В ряду видны `.person__name` (имя) и `.person__role` (короткая роль). Выезжающая карточка берёт полную должность из `data-full`, описание из `data-bio`, инициалы из `data-initials`.
- **Где ещё продаются игры.** Ссылки находятся в `.where__list`. Чтобы добавить магазин, скопируйте строку `<li><a class="buy" …>`.
- **Языки в главной карточке.** Это кнопки внутри `.langcard__tabs`. Слово задаётся в `data-word`, название языка в `data-name`, статус в `data-status` («в продаже» или «в работе»).

## Публикация

Сайт публикуется через GitHub Pages из ветки `main`, папка `/ (root)` (Settings → Pages → Deploy from a branch). Каждый `git push` в `main` обновляет сайт примерно за минуту-две.

Если подключите свой домен (Settings → Pages → Custom domain), поменяйте в `index.html` три адреса: `og:url`, `og:image` и `canonical`. Через них WhatsApp и Telegram показывают превью ссылки.

## Что стоит заменить или проверить

- **Фото Елены и снимки с форумов** вырезаны из сжатого буклета и выглядят мягко. Лучше прислать оригиналы и заменить файлы в `assets/img/photos/` с теми же именами.
- **Материалы от Елены (встреча 02.11.2026):** отобранные благодарственные письма, все сертификаты и методики, фото команды, дополнительные фамилии, правки филологов, недостающие игры.
- **Слово «семья»** на узбекском (Oila), казахском (Отбасы) и белорусском (Сям’я) стоит показать носителям языка.
- **Цены комплектов** «Детский сад» (7 000 ₽) и «Школа» (8 700 ₽) взяты из буклета. Их нужно подтвердить.
